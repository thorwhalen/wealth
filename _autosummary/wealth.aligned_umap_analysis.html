Compute one or several embeddings for the given data (and specific tickers)

Parameters:

  • data (Data (list[DataFrame])) – list of dataframes with ticker indices. Note specifying it will result in getting this from data/csv_derived.zip

  • tickers (TickerSpec (Union[str, int, Iterable])) – iterable of tickers, or string of json file to get these, or string specifying how to computer these from data

  • normalizer – sklearn transformer (has .fit & .transform) to preprocess values (example; std_normalizer (= StandardScaler()), or pca_normalizer

  • reducers – An AlignedUMAP instance or specification (ReducerSpec) to get one.

  • reducer_to_save_name – How to compute a save name/key from a reducer instance

  • save_dirpath – What directory to save the data into
